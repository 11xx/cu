# Firefox capability matrix

This matrix names the current boundary from the Python validation, native host,
extension dispatch, and fixture tests. A supported row means the bounded
operation and its refusal contract are implemented; it does not mean Firefox
will accept every application effect or emit trusted events.

| Capability | Current boundary and authority | Source and fixture evidence | Bounded successor |
| --- | --- | --- | --- |
| Page query/read | Supported through an active read grant; values are opt-in and secrets are redacted. | [`collector.js`](../browser-extension/collector.js), [`test_browser_read.py`](../tests/test_browser_read.py), [`extension.test.mjs`](../browser-extension/extension.test.mjs) | Add a consumer only with a bounded result schema and redaction review. |
| Click/focus/fill/scroll | Supported with an interaction grant, document generation, and stable element ref. Read grants refuse. | [`collector.js`](../browser-extension/collector.js), [`test_browser_control_cli.py`](../tests/test_browser_control_cli.py), [`control.test.mjs`](../browser-extension/control.test.mjs) | Add one operation with a fixture that proves refusal and immediate effect separately. |
| Ordinary select | Supported for one single-select control with an interaction grant, stable ref, and exactly one unambiguous option value or visible label. Missing, duplicate, disabled, sensitive, stale, detached, and read-only cases refuse before dispatch. The result reports the requested identity, observed value/label, document/generation, and explicit grant provenance. | [`collector.js`](../browser-extension/collector.js), [`background.js`](../browser-extension/background.js), [`browser_read.py`](../src/cu/browser_read.py), [`control.test.mjs`](../browser-extension/control.test.mjs), [`extension.test.mjs`](../browser-extension/extension.test.mjs) | Navigation, tab transfer, and window authority remain separate successors. |
| Granted-tab reload | Supported for the active tab in the focused window under an interaction grant with the observed document and generation. An accepted reload revokes the grant, refuses queued requests, cancels waits, and stops the collector before one `tabs.reload`; the receipt names the revoked grant and grants nothing to the new document. Pre-dispatch refusals leave the grant intact, while a tab lost before dispatch or a rejected reload stays revoked. Page load is not observed. | [`background.js`](../browser-extension/background.js), [`browser_read.py`](../src/cu/browser_read.py), [`browser_read_cli.py`](../src/cu/browser_read_cli.py), [`extension.test.mjs`](../browser-extension/extension.test.mjs), [`test_browser_read.py`](../tests/test_browser_read.py), [`test_browser_read_cli.py`](../tests/test_browser_read_cli.py) | Navigation and tab transfer/Stop authority are separate successors; cache-bypass reload is unsupported. |
| Synthetic hover | Supported as bounded event dispatch; it is not CSS `:hover`, a trusted event, or an OS pointer move. | [`collector.js`](../browser-extension/collector.js), [`control.test.mjs`](../browser-extension/control.test.mjs) | Native CU hover is separate and must use a visible frame plus CU interlocks. |
| Wait | Supported for bounded DOM/media states with generation checks and cancellation. | [`collector.js`](../browser-extension/collector.js), [`extension.test.mjs`](../browser-extension/extension.test.mjs) | Add only a named state with a fixture that distinguishes timeout from absence. |
| Viewport capture | Supported for the active granted tab; capture identity is bracketed by document snapshots and bounded to PNG bytes/pixels. An optional explicit CSS-viewport region is cropped using the validated image/viewport scale. | [`background.js`](../browser-extension/background.js), [`browser_read.py`](../src/cu/browser_read.py), [`browser_read_cli.py`](../src/cu/browser_read_cli.py), [`extension.test.mjs`](../browser-extension/extension.test.mjs), [`test_browser_control_cli.py`](../tests/test_browser_control_cli.py) | A real consumer must define retention and evidence export before broader use. |
| Region/full-page/stitch capture | One bounded CSS-viewport region is supported. The result retains requested and returned CSS coverage, source/image pixel coverage, browser tab/document/generation identity, and no native-input authority. Full-page capture and stitching remain unsupported; the extension still uses one `tabs.captureVisibleTab` viewport. | [`background.js`](../browser-extension/background.js), [`collector.js`](../browser-extension/collector.js), [`browser_read.py`](../src/cu/browser_read.py), [`browser-extension/README.md`](../browser-extension/README.md) | Add another capture mode only as a named successor with its own geometry, identity and budget contract. |
| Tab/window selection | A CU session binds the active tab, or a named tab even in the background, with `cu web grant` and releases it with `cu web stop`; no browser click is involved. Actions require the bound tab to be active in the focused browser window; same-class desktop windows are not interchangeable. | [`background.js`](../browser-extension/background.js), [`browser_read.py`](../src/cu/browser_read.py), [`extension.test.mjs`](../browser-extension/extension.test.mjs) | Add explicit tab/window identity only with lifecycle and cross-window fixtures. |
| Browser chrome shortcuts | Firefox/Zen semantic bindings are discovered from configuration/profile data and dispatched through CU; effect remains unverified until observed. | [`browser.py`](../src/cu/browser.py), [`actions.py`](../src/cu/actions.py), [`test_browser.py`](../tests/test_browser.py) | Probe each auxiliary context with a disposable tab; never stock-fallback or replay uncertain delivery. |
| Document/capture identity | Supported through document ID/generation for browser evidence and CU frame/target descriptors for compositor input. Region capture additionally refuses image/viewport scale drift and records quantized returned coverage. | [`browser_read.py`](../src/cu/browser_read.py), [`background.js`](../browser-extension/background.js), [`frames.py`](../src/cu/frames.py), [`test_frames.py`](../tests/test_frames.py) | Bind CSS rectangles to CU frames only after geometry association is proven (B14). |
| Trusted events/CSS hover | DOM operations stay synthetic. In Chromium with the debugger attached, `--input debugger` sends real click, hover, text, named-key and wheel input to a point the collector checked; receipts name backend `debugger` and stay unverified. Firefox refuses. | [`collector.js`](../browser-extension/collector.js), [`background.js`](../browser-extension/background.js), [`browser-extension/README.md`](../browser-extension/README.md) | Measure genuine delivery on applications that reject synthetic events. |
| Debugger evidence (Chromium) | Supported on a bound tab with an interaction grant after `cu web debug attach`: bounded console failures, request metadata without query strings, headers or bodies, and accessibility roles, names and states with values opt-in. Ends with the grant, `cu web debug detach`, or a detach by the browser or user. Firefox refuses. | [`background.js`](../browser-extension/background.js), [`browser_read_cli.py`](../src/cu/browser_read_cli.py), [`extension.test.mjs`](../browser-extension/extension.test.mjs) | Trusted input and full-page capture through the same attachment. |
| Iframe/shadow/virtualized traversal | Unsupported or bounded as an omission; contents are not recursively traversed and virtualized items may not exist in the observed page. | [`collector.js`](../browser-extension/collector.js), [`extension.test.mjs`](../browser-extension/extension.test.mjs) | Choose one explicit traversal capability with origin, lifetime, and budget rules. |
| Native backend fallback | No automatic browser-native fallback after a refusal or uncertain effect. CU `uinput` and compositor keyboard backends are explicit per command. | [`actions.py`](../src/cu/actions.py), [`compositor.py`](../src/cu/compositor.py), [`guide.py`](../src/cu/guide.py) | Measure a named backend against a named browser before adding a capability. |
| Persistent install/signing | Not part of the temporary Firefox route; setup is explicit and does not silently restart or publish a profile. | [`browser_read_cli.py`](../src/cu/browser_read_cli.py), [`browser-extension/README.md`](../browser-extension/README.md) | A signed distribution lifecycle needs separate authority and review. |
| CSS-to-compositor projection | Unsupported. Browser CSS rectangles and browser-rendered captures are not CU logical frames. | [`collector.js`](../browser-extension/collector.js), [`browser-extension/README.md`](../browser-extension/README.md) | B14 must prove identity and geometry before any projection consumer. |

The current CLI/protocol probe returns an empty helper list with exit 0 for the
read-only host query, while an unknown action is rejected by argparse with exit
2. Those are different outcomes: an installed capability with no active grant
is not an unsupported operation. Existing Firefox audit debt remains separate
from this matrix.
